## 更新内容

**v0.9.0：品牌升级——「沉浸口语」，界面全面换新**

### 品牌更名

- 应用正式更名为**「沉浸口语」**（原 ImmersiveTranslator）：安装包、开始菜单、安装目录、窗口标题、托盘提示与各处文案统一改口；功能与数据不受影响，**翻译历史、密钥、设置全部保留**
- ⚠️ **老版本（≤0.8.1）用户升级注意**：安装目录随新名称变化，升级后系统里会同时存在新旧两份，请到「设置 → 应用」卸载旧的 ImmersiveTranslator，并关掉它的开机自启（或在任务管理器 → 启动中删除指向旧目录的条目）

### 界面重构

- **设置中心**：侧栏按「翻译与工具 / 账号与应用」重新分组，新增顶部面包屑与品牌区；服务商选择与配置改为双栏工作台布局，切换更直观；切换分类自动回到顶部
- **翻译历史**：新增页头与记录统计卡；全选 / 导出 / 清空操作分组收纳，批量操作条样式独立，长列表更好扫读
- **账号页**：登录、资料、登录信息、安全设置改为分区卡片，层次更清晰
- **翻译面板**：品牌区与原文标签细节打磨

### 工程修复

- 修复 CI 依赖审计门禁：source-map-js 钉 1.2.2（event-loop DoS 高危，GHSA-68fv-2mgg-jv7q）
- Rust 代码按新版 rustfmt 规范全量格式化，对齐 CI 门禁
- 清理误入页面模板的第三方采集脚本

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装（升级后记得卸载旧版 ImmersiveTranslator，见上文提醒）。
