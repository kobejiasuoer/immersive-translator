## 更新内容

**v0.10.3：沉浸云正式上线——正式包直连生产服务（www.prismspace.online）**

### 沉浸云正式开放

- 官方服务端已公开部署并完成连通验证：**登录账号即用，无需申请任何密钥**，模型与额度由服务端统一管理
- 正式包缺省直连生产域名 `https://www.prismspace.online`（OpenAI 兼容网关 `/v1/chat/completions`，模型列表 `/v1/models`）
- 令牌过期单飞刷新自动重放，无感续期；未登录 / 额度用尽 / 限流 / 模型未开放等均给出可操作的中文提示
- 开发与内测环境仍可用 `server_endpoint.json` 覆盖指向其它地址

### 从 0.10.1 / 0.10.2 升级

- **0.10.2 用户**：升级后到 设置 → 翻译与工具 点一次「沉浸云」即可启用（0.10.2 中该入口处于隐藏保护状态）
- **0.10.1 用户**：v0.10.1 发布说明中「登录即用」当时超前于服务端部署（入口指向本地联调地址），为此致歉；升级本版后重新点一次「沉浸云」，生产地址会自动填好
- 使用 DeepSeek / OpenAI / Moonshot / 本地 Ollama 等自带 Key 的服务商不受任何影响

### v0.10.1 引入的功能照常提供

- 阅读室随读抽查（行内挖空本地判分联动 SRS）
- 崩溃兜底（日志落盘 + 弹窗提示）、热键注销修复
- DirectML 随包分发 + WebView2 内嵌引导的安装包改进

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
