## 更新内容

**v0.10.0：macOS 全量对齐——Windows 桌面工作台完整登陆 Mac**

### macOS（本次主更新，两轮对齐施工）

- **桌面工作台**：启动直达阅读室主窗口，顶部导航「阅读 / 口语 / 笔记与复习」一键切换，书架、主题、账号状态随手可及；三套主题皮肤（暖棕档案 / 黑曜石声波 / 北欧薄雾）导航岛上一键换装
- **阅读室**：编辑部化排版与书脊侧栏定位全书；**聚焦模式**逐句专注沉浸、行间译文按需展开；点开任意句子弹出**句子解析 / 查词**双页签透镜卡，句法拆解与生词释义一卡看全；底部悬浮播放条支持键盘调节语速与进度
- **口语**：场景大厅用整本书或生词本一键生成陪练场景；点击开麦、静音自动停止；**教练式逐词批改**——你的表达、更地道的说法、要点提示逐层对照；**音素级发音建议**与慢速示范；口语页可直接查看跟读报告与差词训练，异常时给出可行动提示
- **笔记与复习**：**记忆胶带手账**可翻面、可撕下重记；**3 分钟快刷闯关**认读、听辨、开口造句多模态混合出题；复习成果导出 **Markdown 笔记**；**28 天热力图**内化看板一眼看清节奏；全部浮层统一 Esc 关闭
- **翻译浮窗**：**AI 词典卡**自动预取、词条与译文一键切换；四位置朗读整段/本句；历史窗新增批量选择与导出
- **账号**：支持邮箱验证码与密码登录，凭据加密存入钥匙串；单实例防护，双开时自动聚焦已有窗口
- **设置中心**：信息架构重构——侧栏导航、检查更新入口、危险区一键恢复默认、首启引导时序优化

### Windows

- 本版本无功能变更，版本号随产品统一晋升（当前最新仍为 0.9.0 功能集）

> macOS 老版本用户：菜单栏 → 设置 → 关于 → 检查更新，或从本页下载覆盖安装。
