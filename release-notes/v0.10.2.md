## 更新内容

**v0.10.2：沉浸云正式上线（www.prismspace.online），并修正 v0.10.1 的超前表述**

### 沉浸云正式开放

- 官方服务端已公开部署：**登录账号即用，无需申请任何密钥**，模型与额度由服务端统一管理
- 正式包缺省直连生产域名 `https://www.prismspace.online`（OpenAI 兼容网关 `/v1/chat/completions`）；开发与内测环境仍可用 `server_endpoint.json` 指向其它地址
- 令牌过期单飞刷新自动重放，无感续期；未登录 / 额度用尽 / 限流 / 模型未开放等均给出可操作的中文提示

### 修正说明（重要）

- v0.10.1 发布说明中「登录即用」的表述当时**超前于服务端部署**（入口指向本地联调地址），为此向已下载 v0.10.1 的用户致歉
- 已在 v0.10.1 中误配沉浸云的用户：升级本版后到 设置 → 翻译与工具 **重新点一次「沉浸云」**，生产地址会自动填好；或继续使用 DeepSeek / OpenAI / Moonshot / 本地 Ollama 等自带 Key 的服务商

### v0.10.1 全部功能照常提供

- 阅读室随读抽查（行内挖空本地判分联动 SRS）
- 崩溃兜底（日志落盘 + 弹窗提示）、热键注销修复
- DirectML 随包分发 + WebView2 内嵌引导的安装包改进

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
