## 更新内容

**v0.7.0：整本书阅读室上线——从读短文到读完一整本英文书**

### 新功能

- **整本书阅读**：书架可直接导入 **EPUB / TXT / DOCX / PDF 整本书**，自动分章建书、书架呈现书级进度，导入即跳第一章；阅读中可打开**书内目录**任意跳章，一章读完自动推进，全书查的生词照常沉淀进复习闭环——从此长书不用再拆成零散短文硬扛
- **每日阅读目标**：可为阅读时长设每日目标，今日卡实时显示进度环；当天没读够时复习提醒卡会换成「还差 M 分钟，继续读《书名》第 N 章」（没设目标/没书的老用户不受打扰）
- **口语复盘 → 生词本**：口语陪练新增「结束本轮并复盘」——把这一轮**确实没掌握的词**（跟读低分、表达缺失）列出来，勾选后自动查词典补齐释义批量加入生词本，同名词保留原有复习进度；入本后可直达「生成复习笔记 / 去复习」
- **历史与浮窗串联**：翻译历史和浮窗里的英文内容新增「**加入生词本**」「**送到阅读室**」入口——刚翻译过的生词顺手收进复习计划，整段原文一键送进阅读室逐句精读
- **全新应用图标**：Windows / macOS / 移动端三端统一换新装

### 问题修复

- 首次启动新增**引导窗口**：三大能力 + 当前快捷键 + 托盘入口一览，不再「装完一脸懵」；设置 → 关于可重看
- 托盘**左键单击**直接弹出菜单（此前左键无反应，新用户找不到入口）
- 设置 → 关于新增「**开机自启**」开关
- 快速复习窗口每次打开都拉取**最新**生词与复习状态
- 朗读失败不再报模糊错误：按缺凭据 / 网络 / 系统组件分类提示，缺凭据时提供重试与打开设置入口
- 界面渲染异常不再白屏：统一错误页支持重试、关闭窗口、复制诊断信息

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
