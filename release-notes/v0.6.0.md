## 更新内容

**v0.6.0 大版本：阅读室升级为沉浸式英语学习工作台**

### 新功能

- **文件导入**：阅读室支持导入 Word（.docx）与 PDF 文件，自动抽取正文并分句，英文原著、试卷、讲义一键变成可朗读、可翻译、可背词的教材
- **学词笔记**：生词卡支持一键生成结构化学习笔记（音标、释义、例句、词根词缀），笔记库集中管理，可导出为 Markdown 归档
- **口语陪练**：新增口语练习模式，情景对话逐轮语音识别转写，AI 点评你的表达
- **录音直译**：新增「录音直译」悬浮窗，麦克风实时采集语音，边说边出中英对照文稿
- **影子跟读评测**：跟读句子自动录音打分，发音准确度逐词反馈
- **云端 TTS**：接入讯飞语音合成，朗读更自然；支持 SAPI / 讯飞双引擎切换，合成结果本地缓存、重复朗读不再等待

### 其他改进

- 全部窗口启用麦克风授权直通，录音类功能不再被系统授权弹窗打断
- 设置页新增讯飞语音服务配置区（ASR / TTS / 发音评测共用一套凭据）

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
