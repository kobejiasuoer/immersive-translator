## 更新内容

**v0.14.0：托盘直达阅读室、快捷键可视化录制，桌面体验与阅读室交互打磨**

### 托盘与桌面体验

- 托盘图标**左键单击直达阅读室**（此前左/右键都弹菜单），右键保留完整菜单；仅响应松开事件，避免同一次点击重复打开
- 双击打开第二个实例时，改为直接唤起已有实例的阅读室（原为唤起设置窗口）
- **修复任务栏图标缓存问题**：升级后任务栏/标题栏图标不再回退到旧品牌，标题栏小图标与任务栏大图标统一同步

### 阅读室

- 译文遮罩句不再渲染「点击显示译文」占位卡：揭开后点按回遮，遮住时通过工具栏新增的「本句译文」按钮或**按住 H** 临时揭示，界面更干净
- **账号切换竞态防护**：切换学习空间/账号时，旧的列表与文章响应不再回写进新空间，书架、文章列表不再串数据
- 打开文章失败、书不存在或没有可读章节时，给出可操作的提示并自动刷新列表，而不是静默无反应
- 学习同步刷新改用单点容错：某一项数据加载失败不再拖垮整组内容刷新

### 快捷键设置

- 三个全局热键（翻译 / 截图 OCR / 阅读室）支持**点击录制组合键**，窗口失焦自动取消录制
- 新增「立即生效」按钮与已生效状态反馈，应用与录制期间自动禁用保存与切换，避免误操作
- 推荐组合改为按需展开，录入体验更清爽

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
