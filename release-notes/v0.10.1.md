## 更新内容

**v0.10.1：沉浸云上线 + 阅读室「随读抽查」，协议更换为 AGPL-3.0**

### 沉浸云（官方翻译服务）

- 新增**「沉浸云」服务商预设**：登录账号即可翻译，**无需配置 API Key**，模型与上游由服务端统一管理，按账号额度计费
- 平台请求自动识别：翻译请求按网关地址判定，自动附带登录令牌；令牌过期单飞刷新后自动重放一次，无感续期
- 服务端错误码全量适配：未登录 / 额度用尽 / 限流 / 模型未开放等都给出可操作的中文提示

### 阅读室：随读抽查

- 新增**「随读抽查」模式**（设置中开启，默认关）：已读句子里出现过的词块/生词变为行内挖空，读完就地作答、本地判分
- 生词再现槽的判分直接联动生词本 SRS 记忆调度；刚见过的词即时回忆最高只记「良好」，防止虚高间隔
- 词块槽不进生词本，纯在正文里给即时反馈；托盘「生词本」独立入口收编进阅读室复习页

### 稳定性与分发

- **崩溃兜底**：启动 panic 不再「双击秒退黑洞」——崩溃信息落盘 `%TEMP%\immersive_translator_crash.log`，release 版弹原生错误框提示日志路径
- 修复热键切换时「注销被占用键报错→误回滚」的问题：启动时默认键被其它软件占用不再影响后续自定义键切换
- 安装包改为 **DirectML.dll 随包分发**（目标机无需另装）+ **WebView2 引导器内嵌**（装完即可用，安装时需联网）；NSIS 安装钩子绕行本机杀软对 OCR 组件的误报

### 开源协议

- 项目协议由 MIT 更换为 **AGPL-3.0**：使用、学习、修改依旧自由；基于修改版的分发（含仅提供网络服务）需同样以 AGPL-3.0 开源
