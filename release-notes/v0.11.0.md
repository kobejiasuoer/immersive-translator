## 更新内容

**v0.11.0：口语场景库 + 云同步 + 阅读发现与订阅 —— 阅读室、口语页全面升级改版**

### 口语场景库（自定义 + 官方目录）

- **自定义场景编辑器**：用一句话描述就能生成专属练习场景，可指定「目标词」重点练习；保存后与内置场景一起出现在口语页
- **官方场景目录**：进入口语页自动拉取最新官方场景（管理后台上下架后重进即生效），按类别浏览，离线时自动回落内置场景

### 云同步（登录账号即用）

- 口语自定义场景支持云端同步：设置 → 账户 → **口语场景云同步**（登录沉浸云账号后可见，手动触发并反馈同步结果），多台设备共用一套场景

### 阅读室「发现」与资讯订阅

- **发现页**：在线书库目录浏览、整本下载、预览确认入库；下载与导入失败均给出可操作的中文原因
- **资讯订阅**：订阅任意资讯源（RSS），书架「订阅」列新增 FeedTab 阅读流；附推荐订阅源清单，一键收编
- 导入正文超长（5 万字符以上）自动截断保护，超长文章不再卡死导入

### 全面视觉改版

- **阅读室**：三段式顶栏外壳；阅读页全新白卡布局（左侧进度轨 + 居中正文栏 + 译文浮层 + 居中走带）；笔记与复习改版为 首页 / 笔记 / 专注复习 / 导出 四态；书架「发现 / 订阅 / 文库」三列直达
- **口语陪练页**：全新视觉（场景条、目标词进度、句内着色、可行动提示）；新增**听力模式**（先听后看）

### 翻译体验

- 翻译被限流（429）时自动退避重试，不再直接失败；失败原因全链路中文透出（含标题栏）
- 正式包直连沉浸云生产服务（www.prismspace.online），开发联调不再影响缺省配置

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
