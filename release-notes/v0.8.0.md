## 更新内容

**v0.8.0：桌面工作台大改版——读、说、记一站直达，另新增账号体系**

### 新功能

- **全新工作台布局**：启动直接进入阅读室主窗口，顶部悬浮导航岛「阅读 / 口语 / 笔记与复习」一键切换，书架、主题、账号状态随手可及，不再满托盘找入口
- **阅读室编辑部化排版**：书脊侧栏定位全书、首字下沉开篇；支持**聚焦模式**（逐句专注沉浸）与**逐行折叠**（译文按需展开）；点开任意句子弹出**句子解析 / 查词**双页签透镜卡，句法拆解与生词释义一卡看全；底部**悬浮播放条**控制朗读、语速与进度
- **口语场景大厅**：整本书或生词本一键生成陪练场景；点击麦克风流式收音、静音自动停止；**教练式逐词批改**——原文、你的表达、更地道的说法、要点提示逐层对照，配**音素级发音建议**与**慢速示范**，知道错在哪一个音
- **笔记与复习三件套**：**记忆胶带手账**把生词卡贴成一条时间胶带，可翻面、可撕下重记；**3 分钟快刷闯关**认读、听辨、口语多模态混合出题，口语题开口说过才算过关；复习成果可导出 **Markdown 笔记**；新增 **28 天热力图**内化仪表盘，学习节奏一眼看清
- **账号体系**：支持邮箱验证码注册登录与密码登录，设置页新增「账号」分区；登录凭据本地加密存储；单实例防护，双开时自动聚焦已有窗口，避免多进程并发刷新令牌被强制下线
- **三套主题皮肤**：暖棕档案 / 黑曜石声波 / 北欧薄雾，导航岛上一键换装

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
