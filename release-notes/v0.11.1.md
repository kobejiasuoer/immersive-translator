## 更新内容

**v0.11.1：官方语音云服务上线——登录即用的云语音识别 / 合成，口语记录多端同步**

### 语音云（沉浸云语音）

- 语音设置页新增「沉浸云」选项：**登录账号即用云端语音识别与语音合成，无需再填讯飞凭据**，能力与额度由服务端统一管理
- 已在用讯飞的用户，登录沉浸云后会**自动切换到云语音**；原讯飞凭据原样保留，随时可切回
- 云语音接入范围：口语陪练（识别与发音评测）、阅读室朗读、实时字幕
- 额度用尽时给出可操作提示（含重置时间），并可直达兑换入口

### 阅读室朗读「云音色」

- 朗读抽屉的「讯飞」档位升格为「云音色」：跟随语音设置页的服务商选择（沉浸云 → 官方网关流式朗读；讯飞 → 原有路径），Edge / 系统本地语音不受影响
- 条件不满足（未登录 / 额度用尽等）时自动回落本地引擎并说明原因

### 兑换码

- 设置 → 账户新增「兑换」入口：输入兑换码即可为账号充值语音额度

### 口语记录云同步

- 口语对话记录与跟读评测记录**跟账号走，多设备同步**；进入口语页自动合并云端记录
- 账户页同步入口升级为多集合同步（口语场景 + 口语记录），一次反馈全部结果

> 老版本用户：设置 → 关于 → 检查更新，或直接下载本页安装包覆盖安装。
