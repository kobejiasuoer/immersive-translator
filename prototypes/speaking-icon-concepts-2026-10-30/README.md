# 沉浸口语图标方向

2026-10-30。用户已选择 **B「书页对话」**，它已成为正式 SVG 母版并同步 APP 与官网资源；其余方案保留为评审候选。

统一 512×512 画布、墨绿 `#1f6b57`、白色及浅绿 `#c9e4d8`，无渐变和阴影。采用可编辑 SVG，由项目现有 Tauri CLI 生成 PNG；不依赖 AI 位图或新增绘图库。

| 标识 | 文件 | 方向 |
| --- | --- | --- |
| A 双向对话 | dialogue.svg / dialogue.png | 两个对向的对话气泡，表达轮流交谈 |
| B 书页对话 | book-dialogue.svg / book-dialogue.png | 书页下缘转为对话尾，表达从阅读进入口语 |
| C 声波对话 | voice-wave.svg / voice-wave.png | 连续声波融入对话轮廓，更突出语音表达 |
| D 语伴 | companion.svg / companion.png | 有表情的对话符号，提供亲切的学习伙伴感 |

`icon-directions.png` 为评审时的对比图，右上角保留当时的 A/文图标；底部显示 16/32/48px 效果。每个方向另有直接由 SVG 生成的 `*-32.png`。32px 使用实际小尺寸输出，16/48px 在对比图中从 512px 母图缩小。

每个候选已查看 512px 与小尺寸，SVG/PNG 尺寸与透明边缘检查完成。品牌配色和承托规则沿用已确认方向；选定后仍需检查 Windows 标题栏、托盘与商店资源再替换。

`render-board.py` 使用本机已有 Pillow 和微软雅黑字体绘制对比图。图标本身的生成继续使用 Tauri CLI。临时生成目录保留，不影响正式代码或资源。
