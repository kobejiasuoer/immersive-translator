沉浸阅读室 让长文读下去。

原文与译文逐句对照，点词查义、点击朗读。文章、词句和阅读进度，都留在同一间阅读室。

下载桌面版 看阅读室功能

Windows 与 macOS 桌面版 · MIT 开源 · 阅读记录保存在本机

一篇外文，
从头读到尾。

原文与译文逐句对照。点一句就从那里朗读，点一个词就查看释义、例句并收藏。文章、词条和阅读进度留在同一处。

先选文章，
接着读下去。

从内置文库开始阅读，也可以导入 EPUB、TXT、DOCX、PDF，粘贴文本或添加公开网页文章。长书按章节整理，读到哪里都能接着往下。

  • 内置分级文库
  • 支持长书与章节
  • 保留阅读进度

点词查义，
留在原句里。

点选句子里的词，查看释义、发音和例句；需要记住的表达可以直接收藏。查完回到原句，继续阅读。

  • 词义与例句
  • 原句一并保存
  • 阅读节奏不断开

收藏的词，
回到复习里。

从阅读室收藏的词句会保留来源，回到复习时仍看得到原句，也能将表达带进口语练习。

  • 按间隔安排复习
  • 从原句回忆词义
  • 把新表达放进对话

读过的内容，
练成自己的表达。

从文章中挑一句，听朗读、跟读练习，再把新词带入对话。阅读里的词句会继续出现在复习中。

朗读、跟读与口语练习的可用方式会随 Windows 和 macOS 版本更新。

  • 听一句，跟读一句
  • 复习文章里的词句
  • 把新表达带进对话

桌面划词，
读完接着看。

阅读室之外，桌面划词翻译和截图 OCR 可以帮你处理浏览器、文档、字幕等屏幕文字。截图先在本机识别，再按你的模型设置完成翻译。

这些能力是阅读路上的辅助入口：遇到一句难懂的话，选中它；遇到图片里的文字，框选它，再回到文章继续读。

常见问题

关于阅读室、模型配置、平台版本和数据处理。

可以从内置文库开始，也可以导入 EPUB、TXT、DOCX、PDF，添加公开网页文章或粘贴文本。扫描版 PDF 的文字识别能力因平台和文件而异。

连接云端模型通常需要填写对应服务商的 API Key。应用也支持配置兼容的本地模型接口，具体取决于你使用的服务。

阅读历史和生词保存在本机。调用翻译或云语音服务时，完成该功能所需的文本或音频会发送给你配置的服务商；截图 OCR 在本机识别。不同平台的存储与服务实现有所区别，详情请查看 项目隐私说明。

两端都在持续建设沉浸阅读室、划词翻译与截图 OCR。桌面系统权限和底层实现不同，个别能力与发布节奏会有差异，请以各平台 Release 说明为准。

当前 macOS 发布包尚未完成 Apple Developer ID 公证。请先确认安装包来自项目 GitHub Releases，再按 macOS 的安全提示在“系统设置”的隐私与安全性中允许打开。
