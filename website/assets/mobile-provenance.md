## 对外状态与边界

- 建议统一标注“移动端预览 · iOS 开发中”。依据 `docs/mobile-execution-2026-10-29.md` 与 `docs/mobile-mac-handoff-2026-10-30.md`，手机主体已按该原型实现并完成 Windows 工作站上的本地构建与确定性回归，但尚未完成 iOS 归档签名、iPhone 真机与物理双端发布验收。
- 本仓库没有经核实的公开 App Store 或 TestFlight 下载入口，官网不能提供虚构链接或宣称手机端已正式上线。
- 游客可本地试读、收藏与复习；云翻译、语音、纠偏与同步需要登录。跨端同章同句、任务与资料接力仍需真实 Windows+iPhone+服务端联调验收。
- 原声仅保存在录制设备，不作为跨端同步素材。不要宣称录音已能在手机与电脑之间同步。
- 个人 EPUB/PDF 依照当前约定由 Windows 规范化后接力。Safari 向 App 的入站分享扩展尚未实现；不要把原型中的分享入口宣传为已可从 Safari 一键导入。
