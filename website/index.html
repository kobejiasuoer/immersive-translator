开始前的小问题。

免费吗？需要 API Key 吗？

Windows 客户端免费下载，采用 AGPL-3.0 开源协议。AI 和语音服务需要联网，可登录沉浸云按账号额度使用，也可配置自己的 API Key，费用由服务商收取。

支持哪些系统与文件？

官网主要展示 Windows 10 / 11 x64 版。支持 EPUB、TXT、DOCX、带文本层的 PDF，以及网页链接与粘贴文本。扫描 PDF、DRM 电子书不支持直接导入。

学习资料会上传吗？

资料默认保存在设备本地。明确开启同步或备份后，相关记录才按你的指示上传；使用 AI 与语音时，提交内容会发往相应服务。详情见隐私政策。

手机端和 Mac 现在能用吗？

手机端这里展示的是设计原型，暂未提供公开下载。Mac 有独立版本，功能与 Windows 分别演进，请以 Release 说明为准。
