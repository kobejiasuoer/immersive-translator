## 1. 设计令牌（可直接抄进 CSS 变量）

> 半透明面一律**每主题显式 rgba**（禁 `color-mix()`，spike `src/ui/tokens.css:1-5` 头注已声明该约束）；以下值即 `:root` / `[data-theme="dark"]` 直接可用。

### 1.1 色板 · 浅色（暖纸）

```css
:root{
  --bg:#FAF8F3;            /* 全局纸底 */
  --surface:#FFFFFF;       /* sheet、菜单、模态 */
  --surface-2:#F3F0E9;     /* 按压态、分段轨道、输入框底 */
  --ink:#201D18;           /* 主文字、主按钮底、激活图标（15.8:1） */
  --ink-2:#565147;         /* 次级文字（7.4:1） */
  --ink-3:#736C5F;         /* 辅助文字、meta、overline（4.9:1） */
  --ink-4:#B4AC9E;         /* 禁用、装饰；仅大号/装饰用（2.1:1，不入正文） */
  --hairline:#E7E2D6;      /* 分隔线 */
  --hairline-strong:#D8D2C2;
  --accent:#2B567F;        /* 墨蓝点缀（7.2:1） */
  --accent-soft:rgba(43,86,127,.10);
  --on-ink:#FAF8F3;        /* 墨底文字（15.8:1） */
  --ok:#3F7050;  --ok-soft:rgba(63,112,80,.10);
  --warn:#96631C; --warn-soft:rgba(150,99,28,.10);
  --err:#AE4A3C; --err-soft:rgba(174,74,60,.10);
  --tb-bg:rgba(250,248,243,.86);   /* tab bar/顶栏毛玻璃底（无 color-mix 的兜底） */
  --shadow-sheet:0 -8px 40px rgba(32,29,24,.14);
  --shadow-pop:0 10px 30px rgba(32,29,24,.16);
}
```

### 1.2 色板 · 深色（暖炭）

```css
[data-theme="dark"]{
  --bg:#1A1815; --surface:#24211D; --surface-2:#2E2A25;
  --ink:#ECE7DD; --ink-2:#BFB8AA; --ink-3:#938B7C; /* 5.3:1 */
  --ink-4:#6B655A;
  --hairline:#35312A; --hairline-strong:#453F36;
  --accent:#8FB3D4; --accent-soft:rgba(143,179,212,.14); /* 8.1:1 */
  --on-ink:#1A1815;   /* 纸色按钮上的文字（14.4:1）；深色下主按钮=纸底 */
  --ok:#85AC90; --ok-soft:rgba(133,172,144,.14);
  --warn:#C9A15C; --warn-soft:rgba(201,161,92,.14);
  --err:#D98376; --err-soft:rgba(217,131,118,.14);
  --tb-bg:rgba(26,24,21,.86);
  --shadow-sheet:0 -8px 40px rgba(0,0,0,.5);
  --shadow-pop:0 10px 30px rgba(0,0,0,.55);
}
```

对比度为本定稿会话实测（脚本计算 WCAG 对比度，2026-09-25 复跑）：正文/辅助文字 16 组全部 ≥4.5:1；唯一低于 4.5 的是 `--ink-4`（2.1/3.1:1），仅限禁用与装饰用途。**主题范围**：全局浅色/深色（跟随系统+手动，「我的 → 外观」）；阅读页内追加「纸色/纯黑」阅读主题（只影响正文区，token 迁自 spike `tokens.css` sepia/oled）。

### 1.3 色彩使用规则（含未来吸收 B 元素的对比度门槛）

- **墨蓝四处清单**：① tab/图标角标 ② 分段选中、开关 on ③ 进度墨线与进行态 ④ 文字链接。其余一律墨色；主按钮 = `--ink` 底（深色反转）。
- **到期 ≠ 红**：到期 = `--ink` 实心 6px 圆点 + ink-2 文字；`--err` 仅真实错误与评测未达标的负反馈文字。
- **每屏非墨色面积** ≤ 一块按钮或一行标签；同屏彩色种类 ≤2。
- **渐变**：本定稿渐变用量 = 0。未来若引入强调面（如 B 的日出渐变 hero），执行 B §2.2 同款收口：同屏 ≤2 处；头像/周柱等改中性底与中性灰阶只留今日强调。
- **未来引入新色时的对比度门槛**（评审要点 5，实测依据见 §0.1）：辅助文字色在其背景上 ≥4.5:1；深色品牌字只允许 ≥18.66px bold（14pt bold 大文本档，3:1 底线）或换算到 ≥4.5:1 的深一档（`#C23A18` 级，实测 4.79:1@#F4F2EC）；渐变面上的白字须加深渐变或改深字。任何新配色进主干的同一次提交里跑对比度复测（§6.4）。

### 1.4 字体栈与字阶

```css
--font-serif:ui-serif,"New York","Songti SC","Noto Serif SC",Georgia,serif;
--font-sans:-apple-system,"SF Pro Text","PingFang SC",system-ui,sans-serif;
--font-mono:ui-monospace,"SF Mono",Menlo,monospace;
```

零 webfont（iOS 命中 New York + 宋体，天然纸感；原型在 macOS Chrome 命中 Georgia/华文宋体）。

| token | 值 | 字体/字重 | 用途 |
|---|---|---|---|
| `--fs-display` | 32/38 | serif 600 | 页面大标题 |
| `--fs-numeral` | 62/1.0 | serif 500 lining-nums | 今天页到期大数字 |
| `--fs-title` | 20/28 | serif 600 | 文章题、sheet 词条（词条大字 28） |
| `--fs-headline` | 17/24 | sans 600 | 列表主文字、按钮 |
| `--fs-body` | 17/26 | sans 400 | 正文、设置说明 |
| `--fs-reading` | 19/34 | serif 400 | 阅读正文（Aa 可调 15–24） |
| `--fs-meta` | 13/18 | sans 400 | 元信息 |
| `--fs-overline` | 11/16 | sans 500 ls .12em | 区块标签 |
| `--fs-tab` | 10/12 | sans 500 | tab 标签 |

**输入铁律**：所有输入框/textarea 字号 ≥17px（防 iOS 聚焦自动放大），完形、听写、翻译原文编辑、搜索、BYOK 表单一律适用。

### 1.5 间距与栅格

`--sp-1…9: 4/8/12/16/20/28/36/48/64`；屏幕左右边距 20（阅读正文 24）；区块间距 28（视觉小样实测压缩后 16–18 + 发丝线，390×844 一屏放下动线全量）；列表行 ≥52（主行 60/含副文字 72）；触控热区 ≥44×44；`env(safe-area-inset-bottom)` + tab bar 49 + 安全区。

### 1.6 圆角 · 发丝线 · 阴影

`--r-xs:5`（标签/徽章）`--r-s:8`（输入框/小钮）`--r-m:12`（按钮/气泡/分段）`--r-l:16`（sheet 顶角）；分隔一律 1px `--hairline`（禁 0.5px hack）；阴影仅 sheet/pop 两档（§1.1），列表不套卡片——行间发丝线、组间留白。

### 1.7 图标

单色描边 SVG：`viewBox 24`、`stroke-width 1.6`、圆头、`currentColor`、`fill:none`；自建 24 枚（今天/练/书架/生词/我的/播放/暂停/上下句/麦克风/波形/相机/剪贴板/书签/设置/喇叭/慢速/搜索/分享/关闭/加号/对勾/箭头/眼睛/撤销）；tab 图标 25px；热区 44。禁 emoji 与裸字符当图标（治 V6）。

### 1.8 动效与触感

| 场景 | 规格 |
|---|---|
| push/pop | 320ms `cubic-bezier(0.32,0.72,0,1)` |
| 底部 sheet | 280ms 上滑 + dim 淡入；下拉跟手，>120px 或 >0.4px/ms 释放关闭 |
| tab 切换 | 160ms 淡入 + 4px 上移 |
| 按压 | `:active` 背景 → `--surface-2`（或 opacity .78）100ms；不做 scale |
| 判分/揭底 | 翻面 240ms；遮罩揭句 200ms |
| 骨架屏 | 流式等待 2 行灰条 1.2s 呼吸 |
| 通知横幅（应用内） | 顶部弹入 400ms；**60s 无操作自动收起**（继承桌面 #28 提醒卡行为，B §2.5 同款）；系统通知不受此限 |
| 全局 | `@media (prefers-reduced-motion: reduce)` 全部降级为即时切换 |

触感（Tauri haptics 插件，失败静默）：tab 切换/评分/收词/开麦 = light impact；清空今日到期 = success notify。

## 6. 实现注意

### 6.1 栈与 iOS 16 CSS 兼容

- Tauri 2 iOS + React 19；`viewport-fit=cover` + `env(safe-area-inset-top/bottom)`。
- **禁**：`color-mix()`（iOS 16.2+，spike `src/ui/tokens.css:1-5` 已声明）、`oklch()`、CSS 嵌套、`:has()` 依赖、`text-wrap: balance`；`100dvh` 需 iOS 16.4+，布局高度用 `100%` 链打底、`dvh` 渐进增强。
- `backdrop-filter` 必须 `-webkit-` 前缀 + `--tb-bg` 显式 rgba 兜底（毛玻璃仅 tab bar/顶栏/sheet 头）。
- 输入 ≥17px 防聚焦缩放；`-webkit-tap-highlight-color: transparent` + 自绘 `:active`；`overscroll-behavior: contain`。
- 按住说话：`touch-action:none` + `preventDefault` + `-webkit-touch-callout:none`；`pointerup/pointercancel` **挂 document 委托**（录音态重渲染换元素后仍能收到，v2 踩过的坑）；<350ms 判误触。
- 长文阅读：分段落 DOM + `content-visibility:auto`（spike S2 600 句压测教训）；动效只动 `transform/opacity`；`prefers-reduced-motion` 全局尊重。
- 键盘：`visualViewport` resize 适配（完形/听写/字幕流/聊天输入）。

### 6.2 复用现有判分 / SRS 内核（`immersive-translator-mobile/src/core/`）

- **`core/judge.ts`**：`norm`/`levenshtein`/`judge`（perfect/close/trap/wrong 四态，含直译陷阱命中与冠词剥离）与 `wordDiff`（LCS 词级三色）已是纯函数——识别/完形/听写三形态判分直接复用，勿重写；文件头注明的「M1 时迁入 packages/reader-core」继续执行，迁移时保持函数签名。
- **`core/srs.ts`**：`GRADE_INTERVALS`（10 分钟/1/3/7 天四档）与 `gradeSrs`（ease 1.3–2.8 夹紧、lapses 计数）与桌面 `readerSrs.ts` 同口径——复习流、快速复习（清一张）、生词页见面时间全部走这一份；跨端一致是同步体验的一部分（v1 决策 4）。
- `core/types.ts` 数据模型沿用 `contracts/reading-room.schema.json` v1 口径；`core/data.ts` 里的 `MINI_DICT`（7 词条假词典，`data.ts:101-110`）在接入真词典（#6 LLM 词典卡）后删除，禁止带进 v3。

### 6.3 store.ts 数据演进（现状 `src/store.ts:20-96`）

- 现状是内存态：`AppState { theme, vocab, articles, sheet }` + `useSyncExternalStore` + `actions`（setTheme/saveWord/deleteWord/gradeWord）+ 内置 `speak()`（onend + 估时兜底双保险，`store.ts:127-154`，**保留复用**）。
- **演进顺序**：① 保持 `actions` API 形状，底层换持久化（SQLite 经 `tauri-plugin-sql` 或文档目录 JSON），启动时 hydrate；② 新增 `reviewStats`（今日已清/总到期/streak/本周三数，供 #52 三处同源）、`notes`、`settings`、`history` 切片；③ `DEMO_VOCAB`/`DEMO_ARTICLES` 仅 Onboarding「跳过」态可用且全程标「演示」；④ `saveWord`（`store.ts:63-87`）里的演示落点（`sourceArticleId:"trees"` 硬编码）改为真实出处参数。
- **左滑删除 = 撤销 toast 5s**（评审要点 7②）：`deleteWord`（`store.ts:88-91`，现有实现此前零调用）改为「先从 UI 移除 + 快照入 toast 闭包，5s 后真正提交；点撤销恢复快照」，替代确认弹窗；书架删文同机制（生词本不受影响 #30）。
- **streak / 统计计算放 Rust 侧**（评审要点 7①，采纳自 B §7）：时区、跨零点、补签判定在 Rust command 内完成，前端只消费结果值（`今日已清/总到期/streak/本周`）；避免 WebView 本地时区与桌面端口径漂移。
- **BYOK**：请求一律走 Rust command（spike 已验证 WebView 直连受 CORS 限制）；Key 经 Keychain 插件读写，永不进 WebView 存储（#18）。
- **通知**：`tauri-plugin-notification` 或自写 UNUserNotificationCenter：每日定时 + badge 三处同步；深链进快速复习路由（`#demo=quick` 等价物）；应用内横幅 60s 自动收起由前端计时器实现（§3.14）。
- **TTS**：首次播报须在用户手势内触发（iOS WebView 限制）；`onend` 链 + 估时兜底（`store.ts` 双保险）逐句推进；静音开关/audio session 真机验证。
- **分享收词**：Share Extension 原生 Swift target；深链统一 `ita://translate|vocab|shelf`。
