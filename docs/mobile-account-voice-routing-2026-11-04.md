# 移动端账号语音与设置调整 · 2026-11-04

依据用户提供的四张 iPhone 截图，移动端学习服务采用登录账号后经过服务器的路径，不再向用户展示供应商控制台、引擎选择或个人服务密钥。

## 已实施

- 朗读通过账号接口换取一次性票据，连接服务器 TTS；流式识别连接服务器 ASR；发音评测使用服务器 ISE。服务器声音清单为选择器数据源，播放倍率实现语速。
- 翻译、陪练、查词和句子解析复用账号服务与刷新机制。即使旧快照有服务密钥，也不能选择供应商直连。
- 移除移动端原生语音、OCR、LLM 供应商直连命令注册。旧实现可以留在源码，但不能由移动端前端调用。OCR 当前没有移动端消费入口，未新增不可用的服务器功能。
- 旧设置快照迁移清空内存中的供应商密钥，不再读取或写入供应商钥匙串。学习文章、收藏、笔记与练习资料保留；现有账号会话钥匙串照常使用。
- `store.speak` 在登录确认前不请求语音，取消或停止后不启动迟到朗读。语音层以账号、登录代次及本地仓储实例隔离请求和缓存；切换账号不发送旧录音。失败不使用供应商或系统朗读替代。
- 保留此前 iOS 输出会话恢复、音频解锁、停止与录音恢复逻辑。停止尚未发送的合成可以避免发送请求；已在服务器处理的请求没有可撤销计费协议。
- 设置页移除不生效的供应商配置、流式输出及美式／英式假口音选项；语音页和账号子抽屉共用声音、示范语速及麦克风组件。
- 账号页统一命名、压缩同步区域、修正阅读设置入口、作答和阅读统计、邮箱登录及验证码找回方式。细节见 `mobile-account-settings-audit-2026-11-04.md`。
- 同步与权限简版说明区分：录音不参与跨端同步；识别与评分请求会提交音频处理。没有更改桌面版正式隐私政策或商店提交文本。

本次没有重新安装手机应用，也没有进行新服务器语音的物理可听验收。测试替身不能代替真机声音、麦克风或系统通知验证。

## 后续产品建议

- 学习方向应影响内容推荐或练习选择，目前主要是偏好存值。
- 账号页展示权益和真实剩余额度；数据源可用 `/v1/me/quota`，不要从缺失的 config 字段虚构余量。
- 同步显示状态按账号重置，避免短暂显示上一账号的同步时间和错误。
- 提醒功能正在其他聊天并行更新，需统一旧提醒抽屉与新授权/排程状态，不能在拒绝权限或排程失败时显示成功。
