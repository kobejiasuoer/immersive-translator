采用柔和中性色、深绿色操作重点和清晰的内容排版。三页共享页头、账号入口、组件色彩和贴底导航，但保留各自的任务结构：阅读展示内容，口语突出一次表达，笔记先安排复习再管理资料。去掉悬浮胶囊导航的玻璃、厚阴影和大面积高亮，保留已验证的点按、拖动、键盘与减少动态效果行为。

## Design System

色彩集中于 `src/ui/tokens.css`，移除了 `learning.css` 顶部重复的主题定义。

- 亮色：背景 `#F5F7F6`、内容 `#FFFFFF`、主文字 `#17231F`、辅助文字 `#65736C`、品牌 `#176B57`、浅强调 `#E5F0E9`。
- 深色有独立背景/边线/文字及 `--on-accent`，避免浅绿按钮配白字。复习实际计算对比度：主按钮 8.85:1、选中模式 6.54:1、辅助文字 6.46:1。
- 中文及操作界面使用系统无衬线；英文正文使用阅读衬线；首页英文标题不再大面积使用粗衬线。
- 基础间距延续 4px 网格；标准页边距 20px、窄屏 16px，宽屏收敛内容宽度。按钮目标至少 44px，控件圆角 12px，主要面板 18px。
- 贴底导航为 64px 加系统底部安全区。滚动正文单独留位；页头、正文、朗读区使用安全区变量，不假设系统顶部留位必定非零。
- 明确默认、选中、按下、禁用、空态和错误态；保留焦点环、原生正文选择与缩放。动画以现有操作反馈为主，尊重减少动态效果设置。

## 工程与业务保护

工程为 React 19、TypeScript、Vite、Tauri 2；页面由三 Tab 与 push 栈组织，抽屉单独管理焦点；`store.ts` 提供外部订阅状态，浏览器使用隔离 IndexedDB，原生使用 SQLite 和私有 WAV。账号服务、语音服务和存储未被替换。

主要新增组件为 `ui/LearningHeading.tsx`、独立的 `screens/SpeakingHome.tsx`；`services/openPractice.ts` 提取原有创建任务逻辑，旧入口继续导出以兼容调用方。`ui/product.css` 管理共享外壳和控件，阅读、口语、笔记分别拥有业务布局样式。没有新增产品运行依赖。

修改前已将移动端源码复制到 `/tmp/immersive-ui-2026-11-07-baseline`；`changed-files.json` 按这份任务开始时的快照生成，区别于 Git 中原本就存在的大量未提交改动。本轮未清理用户工作区、未重置资料、未修改 API/后端结构/SRS 算法/账号隔离/语音存储。没有增加虚构排行榜、评分、消息数或学习完成记录。

实际行为变化：续读条与列表合并；场景改网格；表达改为单项选择；词条练口语入口前移；空词库引导更准确；键盘视口变化时保持草稿可见。底部导航的功能与手势保留。

## 复核与限制

阅读和口语均完成至少两轮运行画面复核；第二轮修正了宽屏头身对齐、重复来源文字、点击目标、过长进度线、续练表达重复、草稿被缩小视口藏住、空词库无效统计与标签残留阴影。

模拟器软键盘进一步检查时 Mac 锁屏，无法继续输入；本轮不声称物理 iPhone 的软键盘、麦克风权限、真实录音/ASR、完整听读、VoiceOver 与通知实收已重新验证。浏览器视口与单元回归不能替代这些检查。没有伪造服务反馈或练习评分。

本轮完成的是移动端核心体验与共享视觉系统；桌面端和网站没有同步改版。账号与设置页主要统一了共享控件，仍沿用既有信息结构。
