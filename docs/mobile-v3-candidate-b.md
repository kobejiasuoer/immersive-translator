## 1. 设计原则：鲜活而不幼稚的四条边界

1. **能量来自主卡，不来自满屏**。渐变与亮色只出现在「行动点」：主 CTA、streak 主卡、今日进度环、当前进行态（录音中/播放中）。其余界面保持中性纸面——这是「健身 App 的动力感」与「儿童 App 的花哨感」的分界线。
2. **数字是英雄，装饰是配角**。大数字用 800 字重系统字体 + 等宽数字，不用卡通圆体、不加描边贴纸；庆祝动效只在「清空今天/跟读过关/陪练完成」三个节点出现，粒子 ≤ 12 且 600ms 内散尽。
3. **iOS 骨架不动摇**。大标题导航、底部 Tab 毛玻璃、push 转场、底部 sheet、左滑删除——全部按 HIG；「鲜活」只发生在骨架内的色彩、圆角与动效上。
4. **每个色都有语义**。橙=行动/到期、绿=完成/成长、蓝=阅读/信息、紫=练/字幕、红=错误。用户不需要学习颜色，颜色在替文案说话。

### 2.2 渐变与特殊面（唯一三处）

- **日出渐变** `linear-gradient(135deg, var(--grad-a), var(--grad-b))`：仅用于 ① 首页 streak 主卡 ② 主 CTA 按钮 ③ 进度条/进度环的填充段。同一屏出现 ≤ 2 处。
- **主卡深度**：渐变面上叠两层径向光斑增加体积感：`radial-gradient(120% 90% at 85% -10%, rgba(255,255,255,.28), transparent 55%), radial-gradient(100% 80% at -10% 110%, rgba(120,20,0,.18), transparent 60%)`（两主题通用）。
- **毛玻璃**：Tab 栏与顶部通知横幅 `backdrop-filter: blur(20px) saturate(1.8)`（必须带 `-webkit-` 前缀）。

### 2.5 动效体系（修 V10，全部 transform/opacity，尊重 prefers-reduced-motion）

| 名称 | 规格 | 用在哪 |
|---|---|---|
| 按压 | `:active { transform: scale(.97); filter: brightness(.96) }` 120ms ease-out | 所有可点元素 |
| 入场阶梯 | 卡片 `translateY(14px)→0 + opacity` 420ms `cubic-bezier(.2,.8,.2,1)`，每张延迟 +60ms | 页面进入/返回 |
| Sheet 上滑 | `translateY(100%)→0` 320ms `cubic-bezier(.32,.72,.25,1)`，dim 淡入 200ms | 词典词卡、导入、导出、Aa |
| Push 转场 | 跟随系统（UINavigationController 式），Tauri 侧用 CSS 模拟同曲线 | 二级页 |
| 数字滚动 | rAF 600ms ease-out | streak、到期数、统计 |
| 进度环/条生长 | `stroke-dashoffset / width` 700ms ease-out，进场触发一次 | hero 环、续读条、本周柱 |
| 状态色闪现 | 判分反馈面 `scale(.96)→1 + 淡入` 200ms | 对/错/陷阱反馈 |
| 庆祝 | 对勾描边 400ms + ≤12 粒彩点（品牌四色）600ms 散尽 | 清空今天/跟读过关/陪练完成 |
| 通知横幅 | 顶部 `translateY(-120%)→0` 弹入 400ms，60s 无操作自动收起（#28 行为） | 复习提醒 |

### 2.6 组件样式

- **主按钮**：高 52 / r-btn 16 / 日出渐变底 / `--on-accent` 17px w700 / 彩色投影 `0 10px 24px rgba(255,92,56,.32)`（深色 `0 10px 28px rgba(0,0,0,.45)`）；按压回弹。次按钮：`--surface-2` 底 + `--text-1` 字；幽灵按钮：`--brand-soft` 底 + `--brand-deep` 字。
- **卡片**：`--surface` / r-lg 20 / 投影 `0 1px 2px rgba(33,30,24,.05), 0 10px 30px rgba(33,30,24,.06)`（深色 `0 1px 2px rgba(0,0,0,.4), 0 8px 24px rgba(0,0,0,.35)`）；无边框，靠投影与底色差分层。
- **Tab 栏**：毛玻璃 + `--tb-bg`；5 Tab；选中=图标 `--brand` + 文字 `--brand-deep` w600；角标=橙 pill 白字 micro（数字），**不用红**。
- **Chip**：r-pill、`--surface-2` 或语义 soft 底、13px；选中态=品牌浅底+品牌深字。
- **输入框**：`--surface-2` 底 / r-md 14 / 无边框 / 聚焦 `box-shadow: 0 0 0 2px var(--brand)`；完形答题槽=底部 2px 虚线占位（不是全角下划线）。
- **评分四档**：横向 4 枚大按钮（高 56、r-lg、各语义 soft 底+深色字：没想起=`err-soft/err`、很勉强=`warn-soft/warn`、想起来了=`sky-soft/sky`、很轻松=`grow-soft/grow`）；按下即落盘并前进，可回看改评。
- **进度环**：SVG，底环 `rgba(255,255,255,.28)`（渐变面上）或 `--border`（白卡上），进度段=日出渐变描边（SVG linearGradient），端点圆帽，粗 10px。
- **底部 sheet**：grabber 36×5 r-pill `--text-4`、顶部圆角 24、**真实下拉手势关闭**（修 I6）、dim `rgba(20,17,12,.42)`。
- **通知横幅**：顶部悬浮 r-xl、毛玻璃、左火焰圆徽（渐变底白焰）、主文案 15 w700 + 预计分钟 sub、按钮两枚（清一张=主按钮迷你版 / 稍后=次按钮）。
- **空态插画**：单色线性 SVG 场景图（书/麦/卡），`--text-4` 描边 + 一处品牌色点缀，配一句白话 + 一个主行动按钮；禁止纯文字空屏。

## 4. 逐屏交互规格

> 每屏四要素：目的 / 布局 / 关键交互 / 关键状态与空态。P0 屏给全规格，P1 屏给要点。

### 4.1 今天（首页）——视觉小样已按此屏 1:1 实现

- **目的**：3 秒内回答「今天该干什么」；让 streak 与进度成为打开 App 的理由（A3 的解法）。

## 7. 实现注意

**CSS / iOS 16 Safari 兼容（硬约束）**
- 禁用清单：`color-mix()`（tokens.css 头注已声明，iOS 16.2+）、CSS 嵌套、`oklch()`、`text-wrap: balance`、`:has()` 依赖、`scrollbar-gutter`；`100dvh` 需 `height:100%` 兜底；`backdrop-filter` 必须同时写 `-webkit-backdrop-filter`。
- 半透明色全部按主题写显式 rgba（见 §2.1 各 soft 色）；渐变叠光斑用 `background-image` 多层，不用伪元素混色。
- `viewport-fit=cover` + `env(safe-area-inset-top/bottom)`；底部 Tab 栏高度=56+safe-area；`-webkit-tap-highlight-color: transparent`；按压态用 `:active` 而非 JS hover。
- 动效只动 `transform/opacity`（不触发 layout）；全局 `@media (prefers-reduced-motion: reduce)` 关闭入场与庆祝。

**手势与录音**
- 按住说话：`touch-action: none` + `preventDefault` + `-webkit-touch-callout: none` + `user-select: none`；`pointerdown` 在按钮上，`pointerup/pointercancel` **挂 document 委托**（录音态重渲染换元素后仍能收到，v2 踩过的坑）；<350ms 判误触。
- sheet 下拉关闭：pointer 事件跟手 `translateY`，过阈值（120px 或速度>0.4px/ms）释放关闭，否则回弹。

**TTS / 通知 / 网络**
- 系统 TTS：首次播报需用户手势内触发（iOS WebView 限制）；`onend` 链推进+超时兜底；静音开关与 audio session 真机验证（Mac 端已有结论）。
- 本地通知：`tauri-plugin-notification`（v2），每日触发+badge 同步三处（图标/Tab/首页大数字）；深链事件路由进快速复习。
- BYOK 请求一律走 Rust command（WebView 直连受 CORS 限制，spike 已验证 #17）；Key 经 Keychain 插件或自写 Security.framework 命令，永不进 WebView 存储。

**数据 / React 19**
- 落盘：SQLite（tauri-plugin-sql）或结构化文件；streak/统计计算放 Rust 侧（时区与补签一致性）；SRS/判分纯函数与 v1/v2 同源移植（`core/judge.ts`、`readerSrs`）。
- 阅读长文虚拟化保留（spike S2 教训）；sheet/词卡用 React Portal + 焦点陷阱；数字滚动/进度环用 rAF，录音态 UI 走状态机不做整层重渲染。

**字体与资源**
- 全系统字体栈，零外部字体/图片请求（离线可用+审核友好）；图标=单文件 SVG symbol 集合（24 栅格 1.8 描边），一套用到所有屏。
