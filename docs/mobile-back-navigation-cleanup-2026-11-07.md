# 返回交互清理 · 2026-11-07

本轮检查移动端所有页面的返回、退出和关闭入口。共发现 **2 个普通返回确认弹框、1 处录音返回硬拦截**，已统一清理。底部液态玻璃 Tab、页面内玻璃切换栏和侧滑手势保持原有交互。

| 位置 | 原先行为 | 现在行为 |
| --- | --- | --- |
| 口语练习：跟读、表达练习、场景对话 | 未完成时返回弹出「这一句还没有发送」或「这次先练到这里？」 | 点击返回或侧滑自动保留本轮进度与文字草稿，返回来源 |
| 常规复习：填空、听音、识别、开口 | 页头返回弹出「退出复习？」确认 | 直接返回上一页，已评分记录和该轮未提交草稿保留 |
| 口语录音中 | 返回仅提示「请先结束或取消这次录音」 | 自动停止并保留原声后返回，不自动识别或发送 |

练习页右上角「结束」也不再弹确认：本轮已有回答反馈或跳过记录时直接打开复盘；尚未作答时保留进度并返回。复盘页返回不会修改练习时间或重排历史记录。

## 数据与异步收尾

- 口语返回中断当前识别、反馈或评测请求；晚到的响应不会继续发送回答或覆盖草稿。
- 返回前等待正在进行的录音保存。正常原声可重新进入后播放、重新识别；常规开口复习增加未完成录音引用，避免返回后遗失录音入口。
- 空录音和无法补全的音频片段不会造成反复返回失败：保留已有资料并给非阻塞提示。真正的持久化失败仍显示具体错误，允许重试。
- 删除词条、移出书架、跳过未发送草稿、替换未完成练习、退出账号等操作确认保留。登录事务处理中短暂禁用返回也保留。
- 阅读、搜索、设置、导入、笔记及快速复习本来就没有返回确认，没有增加额外步骤。这里不承诺所有临时编辑框都自动保存；本次自动保存范围为口语练习及常规复习。
