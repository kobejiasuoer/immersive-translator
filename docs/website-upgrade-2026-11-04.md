## 完整文案稿

首屏：读过的英语，说成自己的话。从一本书、一篇文章开始，在阅读、跟读和对话中，把新表达练进自己的语言里。下载 Windows 版。免费开源客户端，云服务按额度使用。

阅读：在原文里，读懂。先读英文，按需看译文、查词和句子解析。听原句，收藏值得再用的表达。

互动：一个表达，三次相遇。原句 Yet for want of a red rose is my life made wretched. 自写译文：然而，缺少一朵红玫瑰却让我的生活如此凄惨。for want of 表示“由于缺少”。自写示例 We postponed the trip for want of time. 回忆填空 We postponed the trip ___ time. 学习示例，不是实时 AI 结果。

口语：让这一句，有你的声音。从这句开口；说一段自己的话；听见发音的差别；下次接着练。以句子、章节、今日生词进入口语，自定义场景对话；改进表达与发音，回听录音与练习薄弱词；继续未完成练习。

复习：收藏之后，继续记住。生词留着原句，到期再遇见。完形、听写、开口轮换，笔记可整理并导出 Markdown。

材料：读什么，你来决定。自己的书、文档与网页，也可以发现公版书和订阅 RSS。EPUB / TXT / DOCX / PDF / 网页 / RSS；PDF 需有可提取的文本层。

手机：下一段，随身读。电脑上读过的内容，正在走向口袋里的学习空间。移动端开发中，目前展示已确认原型，暂未提供公开下载。

FAQ：开始前，说清楚。客户端与云服务的区别、Key、文件支持、隐私与同步、平台状态、语音能力与麦克风说明。

收尾：下一句，就从这里开始。下载 Windows 版。查看全部版本与更新说明，macOS 独立版本。源码、反馈、隐私政策与 AGPL-3.0。
