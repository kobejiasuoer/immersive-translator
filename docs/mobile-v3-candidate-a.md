## 0. 一句话

**把 app 当一份「今天该读什么、该复习什么」的报纸来排：暖纸打底、衬线标题、发丝线分层、一枚墨蓝点缀；功能的完成度由 Windows 端功能盘点全量承接，观感的完成度由排版与留白承担，不靠任何装饰堆砌。**

## 1. 设计语言三原则

1. **纸即是界面**。底色就是纸，层级靠留白与发丝线（1px hairline），不靠卡片阴影和圆角容器。全 app 只有三处允许浮层阴影：底部 sheet、下拉菜单、toast。
2. **墨分四色，彩只一点**。文字层级全部由四级墨色承担（§2.1）；全 app 唯一的彩色是「墨蓝」点缀，只允许出现在四处：tab 角标、进行中/选中态、进度墨线、可点链接。语义色（成/警/误）降饱和，只做小面积。
3. **衬线是身份**。标题、数字、英文阅读正文用衬线（New York / 宋体）；按钮、标签、导航用系统黑体。衬线承担「读物」的身份，黑体承担「工具」的身份，两者不混用。

### 2.2 色板 · 深色（暖炭）

深色是「暖炭纸」，不是旧版的蓝灰 `#1d1f26`。层级反转：主按钮变纸色。

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#1A1815` | 全局底 |
| `--surface` | `#24211D` | sheet、菜单 |
| `--surface-2` | `#2E2A25` | 按压态、轨道、输入框底 |
| `--ink` | `#ECE7DD` | 主文字、激活图标 |
| `--ink-2` | `#BFB8AA` | 次级文字 |
| `--ink-3` | `#938B7C` | 辅助文字（5.3:1） |
| `--ink-4` | `#6B655A` | 禁用、装饰 |
| `--hairline` | `#35312A` | 分隔线 |
| `--hairline-strong` | `#453F36` | 输入框描边 |
| `--accent` | `#8FB3D4` | 墨蓝（亮化，8.1:1） |
| `--accent-soft` | `rgba(143,179,212,0.14)` | — |
| `--on-ink` | `#1A1815` | 纸色按钮上的文字（14.4:1） |

**主题范围**：全局主题 = 浅色 / 深色（跟随系统 + 手动覆盖，入口在「我的 → 外观」）。阅读页内追加「纸色 / 纯黑」两种**阅读主题**（只影响阅读正文区，导航仍随全局），对应桌面四主题（盘点 #48），token 同 `tokens.css` 的 sepia/oled 迁移而来。

### 2.3 色彩使用规则（防回潮）

- **到期 ≠ 红**：生词列表的「今天到期」= `--ink` 实心 6px 圆点 + ink-2 文字；`--err` 仅用于请求失败、判分未达标档的负反馈文案。
- **墨蓝四处清单**：① tab/图标角标 ② 分段控件选中、开关 on ③ 进度墨线与「进行中」态 ④ 文字链接。其余一律墨色。
- **每屏非墨色面积**不超过一块按钮或一行标签；一屏内同时出现的彩色种类 ≤2（墨蓝 + 至多一种语义色）。
- 主按钮 = `--ink` 底 + `--on-ink` 字；深色主题反转。次按钮 = 无底 + `--hairline-strong` 描边。文字按钮 = 墨蓝链接。

### 2.4 字体栈（零 webfont，全系统字体）

| token | 栈 | 承担 |
|---|---|---|
| `--font-serif` | `ui-serif, "New York", "Songti SC", "Noto Serif SC", Georgia, serif` | 页面大标题、数字、文章标题、英文阅读正文、例句、词典词条 |
| `--font-sans` | `-apple-system, "SF Pro Text", "PingFang SC", system-ui, sans-serif` | 导航、按钮、标签、元信息、中文界面文案 |
| `--font-mono` | `ui-monospace, "SF Mono", Menlo, monospace` | 直译字幕流时间戳、耗时统计 |

说明：iOS WKWebView 中 `ui-serif` 命中 Apple「New York」，中文回落宋体，天然纸感且零下载（原型在 macOS Chrome 上命中 Georgia/华文宋体，气质一致）。**不引入任何 webfont**——首屏渲染与离线可用优先。等宽只用于时间戳/耗时，不做代码场景。

| token | 值 | 用途 |
|---|---|---|
| `--r-xs` | 5 | 小标签（词性徽章、难度 chip） |
| `--r-s` | 8 | 输入框、小按钮 |

### 2.8 图标

- 单色描边 SVG，`viewBox="0 0 24 24"`，`stroke-width:1.6`，圆头圆角，`fill:none`；颜色一律 `currentColor`。
- 自建 24 枚小集（今天/练/书架/生词/我的/播放/暂停/上一句/下一句/麦克风/波形/相机/剪贴板/书签/设置/喇叭/慢速/放大镜/分享/关闭/加号/对勾/箭头/眼睛），禁止 emoji 与单字充当图标（治 V6）。
- 图标视觉 24，点击热区 44；tab 图标 25（iOS 惯例略大）。

### 2.9 动效与触感（治 V10）

| 场景 | 时长/曲线 | 说明 |
|---|---|---|
| 页面 push/pop | 320ms `cubic-bezier(0.32,0.72,0,1)` | iOS 惯例位移曲线 |
| 底部 sheet | 280ms 上滑 + 背景淡入；下滑关闭跟手 | 手速 >500px/s 直接关 |
| tab 切换 | 160ms 淡入 + 4px 上移 | 不做左右滑移 |
| 按钮/行按压 | 100ms 背景 → `--surface-2`（opacity 0.7） | **不做 scale**，防布局抖动 |
| 判分翻面/揭底 | 240ms | 遮罩揭句 200ms 淡出 |
| 骨架屏 | 流式翻译等待态：2 行灰条 1.2s 呼吸 | 治「假死」感 |

- 全部动效包 `@media (prefers-reduced-motion: reduce)` 降级为即时切换。
- 触感：tab 切换 / 评分 / 收词成功 / 开麦 = light impact；清空今日到期 = success notify（Tauri 触感插件，失败静默）。
- 全局 `:active` 覆盖所有可点元素（skill 检查单：cursor/按压反馈/150–300ms）。

## 4. 逐屏交互规格

### 4.1 今天（Tab 1）——视觉小样即此屏

## 7. 实现注意（iOS 16 Safari / Tauri 2 iOS）

**CSS 兼容（iOS 16 Safari 硬约束）**

- 禁 `color-mix()`——半透明面一律**每主题显式 rgba 变量**（spike `tokens.css:30` 的 `--tb-bg` 模式推广到 accent-soft/ok-soft/err-soft）。
- `100dvh` 需 iOS 16.4+：布局高度用 `100%` 链（html/body/screen 三层）打底，`dvh` 作渐进增强。
- `backdrop-filter` 必须 `-webkit-` 前缀 + 不可用时的 `--tb-bg` 实底兜底（毛玻璃只在 tab bar/顶栏/sheet 头三处使用）。
- `env(safe-area-inset-top/bottom)` + `viewport-fit=cover`；状态栏区由系统绘制，内容从安全区起排。
- 输入框字号 ≥17px 防聚焦自动放大；`-webkit-tap-highlight-color: transparent` + 自绘 `:active`。
- 按住说话：`touch-action:none` + `preventDefault`，**pointerup 挂 document 委托**（v2 brief §3 的坑，录音态重渲染不得替换监听元素）。
- 键盘适配用 `visualViewport` resize（完形输入、听写、字幕流都要）；滚动容器 `overscroll-behavior: contain` 防橡皮筋穿透。
- 阅读正文渲染：长文**分段落 DOM + `content-visibility:auto`**（S2 压测 600 句的教训，见 `docs/mobile-spike-report.md`），禁全量节点同帧布局。
- `prefers-reduced-motion` 全局降级（§2.9）。

**系统能力**

- TTS：WKWebView Web Speech `onend` 不可靠——事件 + 定时兜底双轨（spike 报告 S3a 结论）；静音开关与 audio session 在原生侧处理；引擎切换收进「我的 → 语音服务」。
- 通知：`UNUserNotificationCenter` 本地通知 + badge；「清一张」动作经 deep link 进快速复习路由（`#demo=quick` 的等价物）。
- 分享收词：Share Extension 需原生 Swift target；深链统一 `ita://translate|vocab|shelf`。
- Keychain 读写走 Tauri 插件，Key 永不进 WebView 存储（#18）。
- 触感：Tauri haptics 插件，失败静默。

**渲染与数据**

- 阅读页进度：滚动 + 播放双通道写 `progress`（治 I5），节流 500ms 落盘。
- 持久化：SQLite/文档目录（store 层 P0，治 F7）；演示数据仅 Onboarding「跳过」态使用并全程标注「演示」。
- 图标：内联 SVG 组件（不引图标库运行时）；动效统一 `transform/opacity`。
