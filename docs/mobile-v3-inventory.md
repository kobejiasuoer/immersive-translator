# 移动端 v3 功能盘点（以 Windows 端为唯一桌面基准）

> 日期：2026-09-24 · 产出：本表 + 同内容结构化结果（workflow）
> 基准：`immersive-translator-windows/`（README 自述 v0.2.0 翻译核心；代码里另有阅读室/复习/笔记/口语/跟读/直译/提醒等 README 未展开的大模块，本表全部补入）
> 移动现状：`immersive-translator-mobile/src/` 是 4 Tab spike（今天/生词/书架/我的 + ReaderScreen/ReviewScreen + 词卡 bottom sheet，见 `src/App.tsx:11-117`）；`docs/mobile-v2-brief.md` 已定 5 Tab IA（今天/练/书架/生词/我的）+ 按住说话 + 通知清一张。本盘点沿用 v2 IA 命名。
> 优先级口径：**P0 = 移动端核心卖点**（收词快译 / 精读阅读 / SRS 复习 / 练三件套 / 触点与 BYOK 基建）；**P1 = 应该有**；**P2 = 以后**。拿不准的一律标 P1 并写理由，不静默降级。
