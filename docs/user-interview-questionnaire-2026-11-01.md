# 沉浸口语用户问卷与访谈提纲

日期：2026-11-01。用于起步阶段的需求、体验、额度与付费验证。

## 零、没人愿意填：先用一个问题建立联系

当前用户不足 10 人，下面十题不作为首次联系的默认入口。先得到一次真实回复，再按回答追问；完整问卷用于已经愿意反馈的用户，或作为自己的访谈提纲。

### 已有用户的一句话邀请

> 想了解一个小问题：最近一次想读英文或练口语时，你最后用了什么方法？回一句就行，最近没练也可以，不用填问卷。

收到回答后只追问一个相关问题，例如“当时为什么选这个方法？”或“那次在哪一步卡住了？”。不要立刻把其余问题全部补发。

若愿意进一步交流，再约 10–15 分钟，让用户用自己的一小段非敏感资料或示例完成一个实际任务。让他自己操作，观察障碍；最后带走一段实际练习和反馈。

### 陌生用户的小规模招募

先尝试在允许招募的相关社区寻找近期确有需求的人。普通邀请仍约不到人时，可以做一轮有明确上限的时间补偿：5 位参与者，每位 20 元，共 100 元。这是实验预算建议，不是支付标准。

可复制：

> 想找 5 位平时用 Windows、最近确实有英文阅读或口语需求的朋友，体验一下沉浸口语。约 15 分钟，可以用自己的一小段非敏感资料，也可以用示例；我主要观察哪些步骤难用。预约并参加反馈的用户，每人补偿 20 元时间成本，无论任务是否完成、反馈好坏都一样，不需要好评或购买。愿意参加可以回复我。

补偿不与打卡、购买或好评挂钩。有补偿、强指导的样本用于找使用问题，单独记录；软件付费和自然留存另外观察未获补偿或未受强指导的用户。人工陪练需求也单独记录。

邀请后未回复，可以隔几天跟进一次，仍未回复就停止该次联系。不要连续催促，不把“不回复”直接记成“没需求”。

### 按行为判断下一步

| 观察到的情况 | 先检查什么 |
|---|---|
| 没回复 | 对象是否近期有需求，表达是否清楚，回复负担、信任与渠道 |
| 愿意聊但不愿安装 | 电脑权限、安装信任、时间、现有替代办法 |
| 装好却没完成练习 | 第一次使用的入口、配置与操作障碍 |
| 完成后没有主动回来 | 是否有重复需求，APP 相对现有方法的价值 |
| 主动回来但不购买 | 免费是否已足够，付费新增权益是否明确 |

起步阶段先找 3 位愿意说出具体经历的人，把同样的障碍解决一轮，再招下一批。不同批次记录使用来源和帮助程度，小样本不计算可靠市场转化率。

## 一、已愿意反馈的用户填写版

你好，我们想了解沉浸口语在实际使用中的情况，用于改进产品。没有继续使用、没有解决问题，也请如实填写。无需提供姓名、工作机密或原始录音，大约 5–8 分钟。

1. **最近一个月，你在哪件具体事情上需要读英文或说英文？** 最近一次是什么时候？可以写工作、面试、考试、阅读、旅行或其他真实场景。

2. **过去 7 天，你实际读英文、练习说英文分别有几次？每次大约多久？** 没有做也可以写 0。

3. **目前主要用什么工具或方法完成这些事情？** 最近半年有没有为英语软件、课程或人工辅导花钱？分别买了什么、大约花了多少？

4. **你通常用什么设备学习？** Windows 软件安装、登录、下载或麦克风使用，有没有限制或困难？

5. **第一次使用沉浸口语时，在哪一步卡住？** 有没有别人帮助才完成？如果没有帮助，你会怎么处理？

6. **最近一次使用沉浸口语，你具体想完成什么、实际做了哪些操作、最后停在哪里？** 没有使用过，请写当时为什么没有开始。

7. **有没有用自己正在读的资料练口语？** 如果有，请讲一次实际经历以及相对原有方法的变化；如果没有，当时为什么没走这条路径？

8. **安装后，你主动打开过几次？** 哪些使用是自己想起来，哪些是收到提醒、朋友建议或我们的邀请后发生？最近一次不想继续的原因是什么？

9. **最近一次口语练习中，你录了多少段、每段大约多久、实际查看了几次评分？** 有没有遇到免费额度不足或费用不清楚？当时你实际怎么处理？没有遇到可直接写“未遇到”。

10. **下一周需要练英语时，你准备怎么安排？** 哪些事情希望软件自己解决，哪些需要老师、伙伴或陪练帮助？为什么这样安排？

感谢你的真实反馈。后续如需回访，可自愿留下联系方式；不填写也可以。

## 二、20 分钟一对一访谈版

优先问过去的具体行为，再谈产品和价格。不要求每题都问完；有真实案例就围绕案例追问。

### 真实需求，约 6 分钟

1. 最近一个月，哪件具体事情让你需要读英文或说英文？什么时候发生？有无期限，最终完成了吗？
2. 回忆最近一次，从开始到结束你如何处理？用了哪些资料、工具或人？哪一步最耗时间？
3. 过去 7 天实际读英文、练口语分别几次？多久？计划练但没有练的时候，停在哪一步？
4. 最近常用哪些学习或 AI 工具？最近一次何时使用？过去半年实际买过什么，花了多少钱？
5. 最近一次练习之后，你怎么判断哪里需要改进？有没有可比较的回答或其他结果？无需索取私人录音。

### 实际体验，约 5 分钟

6. 在什么设备和地点学习？Windows 是自用还是工作电脑？安装和麦克风是否有限制？
7. 第一次使用从下载到完成练习经过哪些步骤？在哪停住？谁帮过忙？没有帮助会怎么办？
8. 最近一次打开 APP 想完成什么？用了哪些功能、哪里结束？先听用户讲，不替他解释功能。
9. 有没有把自己的阅读资料带入口语？用过就追问一次真实案例和再次使用情况；没用过就问当时想做什么、为什么没用。

### 持续需求与额度，约 4 分钟

10. 哪几次是主动打开，哪几次是被提醒或受邀打开？每次直接原因是什么？
11. 下一次不能使用 APP 时，你会怎样完成同一件事？换工具、自己做、找人还是暂时放弃？为什么？
12. 最近一次录音几段、每段多久、查看了多少评分？最有用的是识别文字、表达纠错还是发音评分？请举一次具体使用。有没有额度不足，之后实际怎么处理？

### 人工帮助与方案理解，约 5 分钟

13. 最近一次寻求别人帮助解决英语问题，找谁、解决什么、是否付费？需求是操作指导、计划监督、反馈批改还是陪练？分清软件需求和人工服务需求。
14. 展示一个真实可交付的方案后问：下一次需要练习时，你准备采用什么办法，为什么？已有免费能力、原有工具、自备 Key 与付费方案各在哪种情况下合适？
15. 请用自己的话讲讲方案包含什么、有效多久、用完会怎样？哪些条件影响决定？是否误以为包含真人教学或陪练？

## 三、价格验证时再展示的方案卡

问完既往行为再展示，避免价格提前影响回答。先填完下面的真实信息；权益未确定时不收款。

- 价格：拟试 ¥29/月，最终按已确认成本与可交付权益填写。
- 包含的云额度：逐项填 token、识别时长、评测次数，并解释自动评分是否消耗。
- 有效期和重置：按实际系统规则填写，区分自然月额度与滚动周期固定总量。
- 超额后：明确什么仍可用、什么暂停、是否可自行选择加量；未经用户选择不产生额外收费。
- 交付与售后：到账方式、到期行为、退款规则按实际能执行的流程填写。
- 人工服务：明确是否包含；购买人工陪练与购买软件云资源分开统计。

可以追问：

> 看完这个方案，你下一次需要练习时会怎样安排？为什么？

用户主动决定购买时，再提供实际购买途径。记录最终交易和后续使用，不把“不错”“愿意支持”记成付款。

问卷内不先给“9.9/19.9/29.9 你选哪个”之类的价位选项，避免把假想选择当成定价结论。先了解真实支出、使用频率、替代方案和具体套餐理解。

## 四、访谈记录与判断

每位用户记录：

| 字段 | 记录内容 |
|---|---|
| 用户代号与关系 | 不要求实名；朋友或陌生用户 |
| 来源 | 内容、社区、朋友介绍等 |
| 需求 | 最近真实场景、时间频率、是否有期限 |
| 原有办法 | 使用工具、实际花费 |
| 首次体验 | 是否独立完成，获得了多少帮助 |
| 持续使用 | 主动返回和被提醒返回分别计数 |
| 额度 | ASR 时长及段数、评分查看与自动消耗、触顶后采取的办法 |
| 付费 | 具体方案、实际付款、是否出于人情、软件或人工服务 |
| 后续 | 购买后是否继续使用、续费或退款理由 |

区分口头好感、有人帮助才完成、主动回来、实际付钱和购买后继续使用。访谈用于发现问题，小样本不能给出可靠市场转化率。

留出至少 3 天不主动催练的观察窗口，技术支持仍正常提供。如果提供访谈补偿，不与好评、打卡或购买挂钩，分析时单独标记。
