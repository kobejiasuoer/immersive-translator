# 产品命名候选（2026-09-12）

> 目标：中国区首发、中英文名都可用、避开「翻译」字眼（与「沉浸式翻译」区隔）、与「阅读/词块/复习」的产品内核相关。
> 已做一轮网络/App Store 初筛（证据见各条）；**正式采用前仍需**：① 商标局官网（sbj.cnipa.gov.cn）第 9/41 类精确检索；② App Store 提审时的名称占用以苹果为准；③ 域名注册查询。

## 候选（按推荐顺序）

### 1. 读根 ReadRoot ⭐ 推荐
- **含义**：知识在读中扎根（demo 文章里那句 "took root" 的呼应）；「深读 + 生根」正是产品的学习观。
- **初筛**：中英文均未发现同名 App/产品（英文仅印度一家线下辅导中心，不同类目不同市场）。
- **配套**：域名 readroot.cn / readroot.com；Bundle ID com.kobejiasuoer.readroot（或维持与名无关的占位）。
- **气质**：沉稳、好记、两字中文名适合 App 图标。
- **小风险**：与「词根」类产品（词根词缀字典等）概念相邻，但名称本身不冲突。

### 2. 词塾 Chunkademy
- **含义**：塾＝旧式学堂，「词塾」= 词与词块的私塾；英文 Chunkademy（chunk + academy）是造词，大概率干净。
- **初筛**：中文无同名；英文造词未发现使用。
- **气质**：中文品牌感最强、最有「学堂」的学习仪式感。
- **小风险**：「塾」字略生僻，输入/口播稍费口舌；造词英文名需要一点传播成本。

### 3. 词蔓（英文配对待定）
- **含义**：词块＝把词连成藤蔓——**最贴合产品的差异化**（词块/搭配标注是独有资产）；藤蔓生长暗合学习累积。
- **初筛**：中文「词蔓」无同名；英文配对受挫——WordVine（iOS 益智游戏）、VineWords（宗教写作平台）均被占，需另造（如 Lexivine / Ciman 或纯拼音 Ciman）。
- **适合**：如果要把「词块」作为品牌第一卖点，选它；否则概念稍绕。

### 4. 句汇
- **含义**：逐句精读 + 收藏汇总；「词汇→句汇」的文字游戏（我们从句子中收词），独创性高。
- **初筛**：无同名 App（近似的有「句问」「句乐部」「句译」，均不同名）。
- **小风险**：与「词汇」同音异字，口播时需要解释「句子的句」；英文配对待定（拼音 JuHui 或造词）。

### 5. 沐词 Muci
- **含义**：沐＝沉浸其中（呼应「沉浸阅读」的心智，但完全避开「翻译」）；轻、雅、两字。
- **初筛**：中英文均干净。
- **小风险**：含义偏文艺抽象，与「阅读/词块/复习」的功能联想弱一些。

## 已排除（初筛撞名）

| 名字 | 排除原因 |
|---|---|
| 拾词 | 已有「拾词英语」iOS App + 同名 Chrome 划词扩展，类目直接冲突 |
| 词屿 | 已有小众产品「词屿 LexiLuma」（零基础英语），且「星屿单词」近似 |
| WordVine / VineWords | 前者是 iOS 益智游戏，后者是宗教写作平台 |
| 句读 | 已有同名文摘类 App（jvdou），且「句读」是通用古文术语难注册 |

## 定名后 3 件事（进 §12 待办）

1. 商标局第 9 类（软件）+ 第 41 类（教育）精确检索 → 2 周内提交注册（约 ¥600）；
2. 注册域名（.com 优先，.cn 一并）；
3. 确定英文显示名、Bundle ID（若用了与名无关的占位则迁移需在首次提审前完成）、图标方向。
