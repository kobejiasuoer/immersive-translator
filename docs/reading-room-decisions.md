# 沉浸阅读室 · 开发期决定记录（docs/reading-room-handoff.md §14）

按交接说明要求，四个开放问题由开发按最合理默认方案自行决定如下。

1. **翻译引擎**：复用划词翻译的同一套 Provider 与 `translate_stream` 管线；长文按「段」为单位串行翻译（同一时刻只有一个请求在飞），不另设 token 限流。理由：串行逐段天然把并发压到 1，复用管线则设置、密钥、错误分类全部白拿。

2. **抓取范围**：「发送到阅读室」（浮窗按钮与热键）只取**当前选中的文本**：>200 字符直接建文章；≤200 字符也送选中文本并提示「已发送所选内容」，不做 Readability / 前台窗口正文抓取。理由：Windows 端没有浏览器注入通道，前台正文抓取不可靠且超本轮范围；URL（Readability）导入留在 P2 预留接口（`Article.sourceUrl` / `sourceType` 已建模）。

3. **跟读打分**：本轮实现「跟读模式」为**停顿等待**——每句读完暂停，等用户自读后点击「继续」（或回车）；不做本地语音识别打分，不引入 whisper.cpp。理由：评分模型引入成本高且文档未定义评分口径；停顿等待已满足「读完一句停顿等你读，读对才继续」的节奏控制，「读对」的判定留待后续接入。

4. **阅读室窗口尺寸**：默认 1200×800，最小 960×620，可最大化；屏 C 的 380 词典栏在窄窗口下正文列收缩居中（`min(640px, 可用宽度)`），词典栏永不遮挡正文。理由：文档建议的 900 最小宽放不下 640+36+380，列收缩是唯一两全的降级；640 列宽在 640+36+380=1056 以下才收缩，1200 默认宽不受影响。

## 实现期补充决定（非 §14，但影响口径）

5. **TTS 高亮粒度**：句级高亮（屏 A 的 `.pair.is-active`）由「逐句朗读 + sentence/word boundary 事件 + ended 事件」驱动，不使用词级视觉高亮。理由：设计稿 §5 只定义了句级高亮样式，词级高亮属于"自行发挥视觉"，被硬约束禁止；boundary 事件仍被后端发出并消费，用于推进与校验同步。

6. **TTS 复用方式**：在现有 SAPI `tts.rs` 上扩展（不引入 WinRT SpeechSynthesizer）：`GetEvents` 轮询取 `SPEI_WORD_BOUNDARY`/`SPEI_SENTENCE_BOUNDARY` 事件、新增独立「单词发音音轨」、`SetRate` 语速、可选音色、事件目标窗口参数。理由：文档 §9-1 提到的 `SpeakProgress` 是 WinRT API，但仓库现状 tts.rs 已用 SAPI STA 线程稳定工作，扩展它改动最小且与浮窗朗读共享一套引擎。

7. **护眼/纯黑主题**：文档 §3 只给了两个底色（`#f5efdf`、`#0a0a0b`），其余令牌按现有暗色令牌的明度关系推导，见 styles.css `[data-theme="sepia"]` / `[data-theme="oled"]`。理由：不推导无法实现屏 B 的四主题，推导基准沿用官方暗色板的相对关系。

8. **生词到期判定与计数**：全部由 `VocabWord.srs.dueAt <= now` 同源计算（屏 D 左栏「今日复习」、卡片四档评分后的下次间隔、书架徽标共用同一函数 `readerSrs.ts`）。四档间隔按文档定值：忘记 10 分钟 / 困难 1 天 / 一般 3 天 / 简单 7 天。

9. **复习提醒**：本轮以阅读室内的「今日复习卡」+ 书架徽标呈现到期数，不发系统级推送通知（通知插件未引入）。理由：不新增依赖是本轮基调，OS 通知留给后续版本。

## 内容进水口 / 复习触点期补充决定（2026-09-13，对应两个原型已批准）

10. **复习提醒用自绘窗口而非系统 toast**：到点由 Rust 调度（30s tick）弹出右下角应用自绘提醒卡（置顶、不抢焦点、60 秒自动收起）。理由：WinRT toast 的动作按钮（「开始复习/今天先不了」）在本技术栈不可用，而这两个按钮是已批准原型的核心交互；免打扰自行实现（23:00–08:00，可跨零点），不依赖系统专注助手。每天至多一次（`last_shown_day`）。

11. **考试词表 v1 只带考研/四级/六级**：考研=2025 红宝书导出（busiyiworld/maimemo-export），四级/六级=mahavivo/english-wordlists（整理自 2016 版官方大纲）。雅思/高考暂缺可靠开源词表源，UI 不放假目标；覆盖数含大纲内的功能词（the/would 等也算，与竞品口径一致），「未掌握」= 命中 ∩ 生词本且 `intervalDays < 7`（与掌握度分桶同口径）。

12. **内置文库文本来源 Standard Ebooks**（公有领域；O. Wilde 童话五篇 + J. London《野性的呼唤》第一章），经 `scripts/build-intake-assets.mjs` 剥 XHTML 生成 `src/core/data/library.json`。「今日一篇」按本地日期轮换。文库条目 `sourceType` 仍为 `paste`（不扩契约枚举），`sourceUrl = library:<id>` 留作来源追溯；副标题/难度直接带入，跳过标题翻译。

13. **URL 抓取自研正则管线而非 Readability 依赖**：剥噪声块 → 块级转段落 → 实体解码 → 短行/全大写/站点口号行过滤；正文 <150 词判为付费墙类失败，报错文案直接给出「粘贴文本」退路。理由：readability-rs 拉新依赖树（html5ever），对新闻/博客/维基类页面自研管线足够，复杂页面宁可失败不硬猜。

14. **快速复习迷你窗只做识别+完形**：智能路由中「熟词→听写」在迷你窗降级为识别（听写需要 TTS 整句连播语境，留在阅读室复习流）；识别卡建议档固定「一般」，完形卡建议档按 recallJudge 判定映射。每张卡评分即落盘，收起（Esc/✕ = 隐藏窗口）不丢进度；完成后托盘角标清零。

15. **托盘角标**：默认应用图标右上角像素合成红色圆徽标 + 到期数（3×5 点阵数字），零图形依赖；数值由 Rust 侧 `reader_store::due_count` 从 reader_vocab.json 直接推导（与前端 stats 同口径）。30s 调度线程刷新；前端在生词变化时也会主动触发。

16. **每日阅读目标（分钟）v1 只存不追踪**：设置抽屉可调（5–60 分钟），今日卡暂不展示阅读时长进度（阅读时长统计尚未实现），复习目标 = 清空到期。

17. **快速复习/提醒窗跟随阅读室主题**：两个新窗口共用 `localStorage` 的阅读室全局设置（theme/fontPair），与主窗口视觉一致。
